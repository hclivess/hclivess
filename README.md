## Jan Kučera

Systems and protocol engineer in Ostrava, Czechia — consensus, cryptography, storage, P2P, and observability tooling.
Twelve years of Python, increasingly Rust.

### Protocols

- **[bismuth](https://github.com/hclivess/bismuth)** — the first blockchain written from scratch in Python. Fair-launched 2017, no ICO or premine, in production since.
- **[nado](https://github.com/hclivess/nado)** — phone-mineable post-quantum chain: a beacon-keyed weighted draw replaces the hash race, ML-DSA-44 signatures, a STARK-proven zkVM, and a zero-install browser wallet/miner.
- [nado-hardware](https://github.com/hclivess/nado-hardware) — WebAuthn attestation token and hardware wallet from off-the-shelf parts.
- [HoboNickels](https://github.com/hclivess/HoboNickels) — a 2014 proof-of-stake coin revived on a modern toolchain.
